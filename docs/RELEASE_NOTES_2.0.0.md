# CDQAI 2.0.0 Release Notes

Version 2.0 introduces the Unified Evidence Platform. Model scores now enter the same evidence pipeline as deterministic rules. The release adds model evidence, MFN-level findings, priority ranking, actionable and annual reports, and a branded HTML dashboard with plain-language methodology and limitations.

Missing and sparse narratives are retained as completeness evidence but do not populate the actionable queue unless accompanied by another signal.
