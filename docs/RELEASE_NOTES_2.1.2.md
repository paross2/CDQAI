# CDQAI 2.1.2 — Collapsible Dashboard & Findings Explorer

Version 2.1.2 improves dashboard navigation and analyst exploration without changing analytical results.

## Dashboard changes

- How CDQAI Works and About CDQAI are collapsed by default.
- Top Actionable Findings remains open by default and can be collapsed.
- All Findings is available as a collapsed section containing the complete synthesized findings set.
- The All Findings explorer supports text search, categorical filters, confidence ranges, sortable columns, expandable evidence details, and a live result count.

## Stable project layout

The working repository should remain named `CDQAI`. The launcher and installation guide now use stable filenames: `Run_CDQAI.bat` and `INSTALL.txt`. Version identity remains in project metadata, generated outputs, changelogs, and Git tags.
