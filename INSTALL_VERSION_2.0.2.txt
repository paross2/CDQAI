CDQAI VERSION 2.0.2 INSTALLATION

1. Copy or extract the project into its own folder.
2. Create a Python 3.11+ virtual environment named .venv.
3. Install dependencies: .venv\Scripts\python.exe -m pip install -r requirements.txt
4. Copy config\config.example.yaml to config\config.yaml for a new installation, then enter local database settings.
5. Run tests: .venv\Scripts\python.exe -m pytest
6. Launch with Run_CDQAI_2.0.2.bat.

For an upgrade, preserve your existing config\config.yaml because Git intentionally ignores that local file.
